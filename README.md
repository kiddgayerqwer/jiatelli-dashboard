# 嘉特利業績表

嘉特利職人清潔的業績儀表板。從 Google 日曆「黃金單身坤-業務排程」即時讀取訂單，
可依月份、服務項目、地區、新舊客戶查看業績，也能編輯訂單並寫回日曆。

## 使用方式

1. 打開本專案的 GitHub Pages 網址。
2. 第一次使用時，填入 Apps Script「網頁應用程式」網址（結尾是 `/exec`）和金鑰，按「連線」。
3. 連線資訊只存在你這台裝置的瀏覽器裡。在別人的電腦上用完，請按「連線設定 → 清除這台裝置的連線」。

## 安全說明

- 這個儲存庫**不含任何訂單資料、客戶資料或金鑰**，網頁本身打開只會看到空白的連線畫面。
- 資料只在輸入正確金鑰後，從 Google Apps Script 即時讀取到瀏覽器。
- `apps-script/日曆連線程式.gs` 裡的金鑰是空白範本；實際部署的金鑰只放在 Apps Script 與自己的電腦，不要提交到這裡。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 業績表（同一個檔案也可放在桌面資料夾離線使用） |
| `apps-script/日曆連線程式.gs` | 部署在 Google Apps Script 的日曆讀寫程式 |
